# Contributing

Local run:
- flutter pub get
- flutter run

Analyze and test:
- flutter analyze
- flutter test

Notes:
- This app is fully on-device with no external services.
- Scoreboard persistence uses shared_preferences.
- Follow the Ocean Professional theme: primary #2563EB, secondary #F59E0B, error #EF4444, background #F9FAFB, surface #FFFFFF, text #111827.
- Keep UI changes responsive and avoid using context after async gaps.
